# cengizhankose.com

Personal site of Cengizhan Köse: portfolio, blog and contact, in English and
Turkish. React 19 + Vite on the client, one Bun server (`server.ts`) for the
prerendered pages and the read-only posts API.

Commands, architecture and deployment are described in `CLAUDE.md`. The
visual identity (palette, type, layout, the page-frame signature) is in
`claudedocs/design/design-plan.md`.
